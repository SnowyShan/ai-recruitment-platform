  6. AUDIO PLAYBACK SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Three layers, tried in order:

  ┌──────────────────────────────────────────────────────────┐
  │  LAYER 1: Pre-fetched audio map (fastest)                │
  │                                                          │
  │  During "ready" phase, all questions fetched in parallel │
  │  Stored in: prefetchedAudioMapRef = { 0: blobUrl,        │
  │                                       1: blobUrl, ... }  │
  │                                                          │
  │  On question N: check prefetchedAudioMapRef[N]          │
  │  If found → play immediately (no network wait)           │
  └───────────────────────┬──────────────────────────────────┘
                          │ not found (cache miss)
                          ▼
  ┌──────────────────────────────────────────────────────────┐
  │  LAYER 2: On-demand TTS API (medium speed)               │
  │                                                          │
  │  POST /api/interview/tts { text: "..." }                 │
  │       │                                                  │
  │       ▼                                                  │
  │  Interview Module Backend                                │
  │       │                                                  │
  │       ▼                                                  │
  │  OpenAI API (tts-1, nova) → audio bytes → StreamingResponse
  │       │                                                  │
  │       ▼                                                  │
  │  Browser creates blob URL → plays via <audio> element    │
  └───────────────────────┬──────────────────────────────────┘
                          │ OpenAI API fails
                          ▼
  ┌──────────────────────────────────────────────────────────┐
  │  LAYER 3: Browser speechSynthesis (free, lower quality)  │
  │                                                          │
  │  window.speechSynthesis.speak(utterance)                 │
  │  Uses device's built-in voice (Siri voice on Mac/iOS)    │
  └──────────────────────────────────────────────────────────┘

  Generation counter (prevents stale audio):
  ──────────────────────────────────────────
  Every call to speakThenRecord() increments a counter (gen).
  Every async callback checks if the counter still matches.
  If not → the user already moved on, discard this audio.

    gen=1 request ──► fetching...
    user taps Next
    gen=2 request ──► fetching...
    gen=1 audio arrives → gen(1) ≠ current(2) → DISCARD ✗
    gen=2 audio arrives → gen(2) = current(2) → PLAY ✓

  7. TRANSCRIPT CAPTURE SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  The Web Speech API sends results asynchronously and can keep
  sending them even after you tell it to stop. The transcript
  system handles this with two safety nets:

  While answer is being recorded:
  ────────────────────────────────
  Speech API fires onresult events continuously

  Each event:
  ┌─────────────────────────────────────────┐
  │  onresult fires                         │
  │  latest text = "I think the answer is"  │
  │                                         │
  │  → questionAnswersRef[currentQ] = text  │
  │    (always keep the latest version)     │
  └─────────────────────────────────────────┘

  When user taps Next:
  ────────────────────
  ┌────────────────────────────────────────────────────────┐
  │  1. Capture transcriptRef.current into local var       │
  │     (BEFORE stopping, to avoid race)                   │
  │                                                        │
  │  2. cancelSpeech() + stopRecording()                   │
  │                                                        │
  │  3. commitToTranscript(answer):                        │
  │     - check committedRef.has(idx) → if yes, STOP       │
  │       (already written, don't write twice)             │
  │     - committedRef.add(idx)                            │
  │     - use questionAnswersRef[idx] if available         │
  │       (may be more recent than the captured answer)    │
  │     - write "[Q1: question text]\nanswer\n"            │
  │       to fullTranscriptRef                             │
  └────────────────────────────────────────────────────────┘

  At interview end (buildFinalTranscript):
  ─────────────────────────────────────────
  ┌────────────────────────────────────────────────────────┐
  │  Sweep questionAnswersRef for any uncommitted answers  │
  │  (questions where user hit End before tapping Next)    │
  │                                                        │
  │  For each:                                             │
  │    - skip if committedRef.has(idx)                     │
  │    - otherwise commit it now                           │
  │                                                        │
  │  Return fullTranscriptRef.current                      │
  │  → sent to server for Claude evaluation                │
  └────────────────────────────────────────────────────────┘
